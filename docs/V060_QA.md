# RiftGuard V0.6.0 — QA and continuous checks

## Confirmed features in this build
- Four player-selected battle difficulty modes saved in SharedPreferences.
- Difficulty affects spawn count, enemy health, enemy speed, attack damage, wave length, supply rewards.
- Every map-C finale spawns an elite on the final wave; world bosses at 10-C, 20-C, ... 100-C.
- Four unique fortress-mounted weapons with different real in-game damage, cadence and secondary effects.
- Stage-specific battlefield props and map previews derived from deterministic stage seeds.

## Continuous validation
GitHub Actions runs on each push, pull request, manual dispatch, plus **nightly at 03:21 UTC / 11:21 Philippines time**. It downloads and validates public resource pack files, runs Android JVM + Robolectric tests, builds debug APK and uploads rendered screen images. It cannot verify real Android GPU performance or promise zero bugs. Failed scheduled runs are visible to repository collaborators in GitHub Actions, but this is not autonomous assistant monitoring or self-healing.

## Remaining major production gaps
High-fidelity character skeletal animation, truly authored 300 maps, multiple boss models and attack phases, more integrated premium game UI, device safe-area testing, resource packs with genuinely newer high-resolution art. This release does not claim these are complete.
