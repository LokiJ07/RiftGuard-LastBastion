# V0.8.2 fortress / equipment acceptance
The rendered castle remains a layered mix of painted scenery and independent native Canvas components. Three upper ranks now differ by real structural geometry rather than only glow tints; turret masonry buttresses are drawn after the keep, then each independent turret model is rendered above its proper platform. Four families (ballista, cannon, frost, arc) retain independent aim, damage, rate and secondary effects. The hero's six available weapons use a deterministic per-class wrist socket and articulated shoulder/elbow overlays with a gripped hand drawn above the handle, synchronized to weapon timing and casting.

Automated checks: real sprite rendering differences across six weapons, castle silhouette changes across rank 3–5, four mounted platform centers, static rig movement tests, seven render viewport sizes. Limitations: source atlas has baked equipment, so a true rig requires a dedicated weapon-free character sheet with articulated limbs; 4:3/foldable/small-screen ergonomics require physical-device playtesting; rank-specific handcrafted fortress sprites remain a future art asset deliverable.
